**Goal:** 맥미니 Folder Bot 세션·루틴 실행·폴더 파일 변화를 Haiku 요약 카드로 줄인다. 카드를 폴더(= 목표) 아래 작업으로 묶어 «오늘의 축 + 내가 나설 곳 + 목표 카드»를 홈 맨 위에 올리고, 목표를 펼치면 작업·이야기·채팅을 보여 준다. 같은 값을 `board.json`/`board.md`·오케스트레이터 도구로도 낸다.

**Architecture:** 판정·묶기·판 짓기는 순수 모듈 셋(`core/contextCard` · `core/contextTasks` · `core/contextBoard`)에 둔다. 조각 나누기는 `core/contextSegment` 에 둔다. 호스트는 `host/context.ts` 하나가 세션 사건(`sessions.on('state')`)과 파일 감시를 받아 일을 `host/contextQueue.ts` 줄에 세운다. 이 줄은 Haiku를 한 번에 하나만 부르고 디바운스·사용량 80% 멈춤·하루 상한을 지킨다. 저장은 `host/contextStore.ts` 가 맡는다 — 카드는 앱 데이터, 묶음·판은 볼트 `.folderbot/context/`. 볼트 쓰기는 주인 맥(`ownsRoutines()`)만 한다. 게이트웨이(`/api/context/*`)와 MCP(`context_board`)가 같은 판을 낸다. 화면은 `client/Context.tsx` 의 띠(레일·폰 홈 맨 위)와 모달 페이지(상황판 · 목표 펼치기)다 — 루틴 페이지(`modal === 'routines'`)와 같은 꼴.

**Tech Stack:** TypeScript · Node host · React client · `claude -p --model haiku|sonnet`(사람 CLI 로그인) · vitest(`test/unit/**/*.test.ts`) · 스모크 `test/smoke.mjs` + 스텁 `test/fixtures/stub-claude.mjs` · `npm run qa` · `npm run qa:mac`
