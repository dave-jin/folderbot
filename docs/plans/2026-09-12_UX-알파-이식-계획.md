# 채팅·패널 UX — Rondo 알파에서 가져올 것 (계획, 2026-09-12)

Dave 지적: *"현재 디자인이 많이 아쉬워"* — ① 진행 상황·서브에이전트가 안 보임 ② 우측 패널 폭 조절 안 됨 ③ 파일은 최근 변경순이 아니라 실제 폴더.
알파(`dave-jin/rondo-app`, `src/renderer/src/App.tsx` 24.8k줄 · `DESIGN.md`)를 전수 조사한 결과와 이식 계획.

## 0. 현재 Folder Bot 의 격차 (실측)

| 격차 | 원인 |
|---|---|
| 일하는 중인지 모른다 | 채팅에 진행 위젯이 없다. 상태는 헤더 점 하나뿐. `thinking_delta` 는 버림 |
| 서브에이전트가 안 보이고 도구 줄이 도배된다 | 호스트가 `parent_tool_use_id` 를 무시 → 서브에이전트의 도구 호출이 메인 대화에 평평하게 섞인다(스크린샷의 Bash 벽) |
| 우측 패널 폭 고정 | 리사이즈 핸들이 좌측 레일에만 있다 |
| 파일이 "최근 변경순" 목록뿐 | `/recent` 만 그린다. 트리 API(`/files`)는 있으나 첨부 피커에서만 쓴다 |

- 레일 행: 경과시간 명도 3단, hover 액션은 고정폭 슬롯 크로스페이드
