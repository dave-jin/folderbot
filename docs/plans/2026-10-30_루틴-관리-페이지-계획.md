# 루틴 관리 페이지 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 모든 Folder Bot 루틴을 한 페이지(시간표·몰림·성공/실패·문제 먼저 목록)에서 보고 고치고, 놓친 회차는 «다음 회차 전까지» 보충하고, 오케스트레이터가 모든 봇 루틴을 고치면 그 폴더 CLAUDE.md 구역에 남고, 정기보고가 같은 계산을 읽는다.

**Architecture:** 판정·집계·시간표는 순수 모듈 `src/core/routineBoard.ts` 하나에 둔다. 호스트는 `src/host/routineBoard.ts` 에서 봇 목록 + 실행 기록(`runs-*.jsonl`) + 변경 기록을 읽어 그 모듈에 넣고, 게이트웨이(`/api/routines/overview`)와 MCP(`routines_overview`)가 같은 결과를 낸다. 보충 규칙은 `src/host/routines.ts` 에서 바꾸고, 켜질 때의 실행은 동시 2개 줄(`StartQueue`)에 세운다. 화면은 `Cleanup` 처럼 모달 페이지 `src/client/Routines.tsx`.

**Tech Stack:** TypeScript · Node host · React client · croner · vitest(`test/unit/**/*.test.ts`) · 스모크 `test/smoke.mjs` · `npm run qa` · `npm run qa:mac`

**Spec:** `/Users/dave/Library/CloudStorage/Dropbox/PARA/2. Area/제품_FolderBot/01_기획/2026-10-30_기획_루틴-관리-페이지.md` · 목업 `…/03_디자인/2026-10-30_루틴-관리-목업/루틴-관리-목업.html`

## Global Constraints

- 루틴 정본은 그대로 `.bot.yml`(오케스트레이터 `.claude/routines.yml`) — 저장은 `registry.saveRoutines` 만 쓴다. 새 저장 형식을 만들지 않는다.
- `approve`(승인 수준)는 어느 MCP 도구에도 넣지 않는다 — 사람만 화면에서 바꾼다.
- 보충: 반복 루틴 = 다음 정해진 회차 전이면 얼마나 늦었든 가장 최근 놓친 회차 한 번 · 한 번짜리 = 6시간(`CATCHUP_WINDOW_MS`) 그대로 · `catchup: false` 는 보충 안 함.
- 켜질 때(끊긴 회차 재시도 + 보충) **동시 2개**까지, 예정 시각 이른 것부터. 제시각 루틴은 늦추지 않는다.
- 루틴은 `.claude/ops.yml` 의 `host:` 호스트에서만 스케줄·보충한다(없으면 지금처럼 어디서나). 판정은 `ownsPeer({host}, hostNames)`.
- 몰림 기준: 10분 칸 동시 수 0 빈칸 · 1~2 옅음 · **3 이상 노랑** · 5 이상 빨강. 평균 걸린 시간 기록이 없으면 5분.
- 상태 묶음 순서: `fail`(실패·시간 초과) → `missed`(놓침) → `unknown`(결과 줄 없음) → `finished`(끝난 일회성) → `off`(꺼 둠) → `ok`(정상).
- CLAUDE.md 구역 표지: `<!-- folderbot:routines -->` … `<!-- /folderbot:routines -->` · 오케스트레이터는 볼트 루트 `CLAUDE.md` 가 아니라 `.claude/orchestrator.md` · `CLAUDE.md` 가 없으면 만들지 않는다 · 구역 밖은 바이트 그대로.
- 변경 기록: `<볼트>/.folderbot/ops/routine-changes.jsonl` · 구역에는 최근 5건.
- 화면 글은 한국어 · `DESIGN.md` 검은 유리 계약 · 폰은 `docs/LAYOUT.md` 불변식.
