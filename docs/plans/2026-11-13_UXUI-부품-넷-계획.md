> Dave 가 정한 것(11/13 카드): 승인 카드의 [허용] 은 **오른쪽 끝으로** · 세션 하나 지우기는 **바로 지우고 10초 되돌리기**(턴이 도는 세션만 확인창)

## 목표

창 · 단추 · 고르기 · 지우기 확인을 한 모양으로 모은다. 새 색 · 새 글꼴 · 창 안 내용은 건드리지 않는다.

## 건드리지 않는 것 (Dave 가 날짜를 박아 정한 화면)

- 멈추기 단추 · 폰 하단 탭 넷 · 모델 시트
- 세션 정리 창의 상태 탭 다섯(11/11)과 거르기 알약 — 알약은 여럿을 함께 켜는 거르개(`toggleF`)라 세그먼트로 바꾸지 않는다(기획서와 다른 점)
- 모델 바꾸기 확인창의 «다시 묻지 않기»(9/15 문안)

## 두 묶음으로 나눠 배포한다

한 번에 넣으면 창 열 개와 단추 수십 곳이 같이 바뀌어 고장이 났을 때 어디서 났는지 가리기 어렵다.

### 묶음 1 — 지우기 확인 · 단추 · [허용] 자리

| 무엇 | 어떻게 | 지키는 검사 |
|---|---|---|
| 브라우저 기본 확인창 13곳 | `askConfirm`(앱 확인창)으로. 지우는 일이면 `danger: true` — 빨간 테두리 단추, ⏎ 를 묶지 않는다(초점은 [취소]) | 유닛 — 화면 코드에 `confirm(` 이 남아 있으면 빨강(`askConfirm` 의 호스트 없는 때 대비 한 줄만 예외) |
| 세션 하나 지우기(오른쪽 패널 · 채팅 머리줄 메뉴) | 묻지 않고 지운 뒤 토스트 «되돌리기 (10초)» → `POST /sessions/restore`. 턴이 도는 세션만 확인창 | 스모크 — 지우면 확인창 없이 사라지고, 되돌리기로 돌아온다 · 도는 세션은 확인창 |
| 할 일 지우기(폰 편집 시트) | 묻지 않고 지움(5초 되돌리기는 이미 있다) | 스모크 |
| 파일 휴지통 | 묻지 않고 옮긴 뒤 토스트 «되돌리기» → `POST /undo` (폰에는 ⌘Z 가 없다) | 스모크 |
| 기기 끊기 · 토큰 지우기 · 볼트 루트 바꾸기 | 확인창을 새로 둔다(`danger`) | 스모크 — 설정의 [끊기] 는 확인창을 지나야 호출 |
| 토스트 | `say(글, { label, run, ms })` — 단추 하나를 달 수 있다. 단추가 있으면 `ms` 동안 남는다 | 유닛(없음) · 스모크로 본다 |
| 주 행동 단추 | `btn on` 18곳 → `btn primary`. `btn on` 은 켜진 상태에만 | 유닛 — `className="btn on"` 이 화면 코드에 없다 |
| 정의 없는 변형 | `btn sm` · `p` · `g` 를 정의한다: `.btn.sm`(높이 24 · 12px) · `p` → `primary` · `g` → `ghost` | 유닛 — `btn` 뒤 낱말은 `primary · ghost · danger · sm` 과 화면 고유 접두(`cx-` · `dawn-`)뿐 |
| 할 일 제안 [넣기] | 초록 → 흰 주 단추 | 스모크 — 바탕색이 `--w` |
| 승인 카드 | [거부] … [이 세션에서 항상 허용] [허용]. 키 안내는 [거부] 옆. ⏎ · ⎋ 는 그대로 | 스모크 — [허용] 이 줄의 오른쪽 끝 · ⏎ 로 허용 |
| 확인창 · 이름 묻기 | 머리줄에 ✕ | 스모크 |

### 묶음 2 — 창의 한 틀 · 고르기 · 체크 · 배지

창 열 개를 한 틀(`Modal` — 머리줄 · 거르기 줄 · 본문 · 발, 폭 작게 480 · 보통 720 · 넓게 1080, 닫기 셋)로 옮긴다. 루틴 편집의 [취소][저장] 을 발로, «끝나면 푸시» 를 세그먼트로, 고친 내용이 있으면 닫기 전에 묻기. 체크 한 모양 · 숫자 배지 한 모양 · 루틴 창의 이모지를 선 아이콘과 상태 점으로 · 상황판의 «루틴» 을 탭에서 단추로. 묶음 1 을 배포한 뒤 따로 계획을 보탠다.
