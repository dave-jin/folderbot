**세션 줄의 규칙**

- 순서: 묻는 중이라 올라온 세션(`askLifted`) → 채팅 세션(지금 목록 순서). 자동화 세션은 탭으로 세우지 않는다.
- 탭 하나: 상태 점(일하는 중 · 내 답 기다림 · 오류 · 안 읽음 — 없으면 점 자리도 없다) · 이름(최대 168px · 말줄임) · 회사 표식 · 일하는 중이면 경과. 올리면 ✕(지우기), 두 번 누르면 이름 고치기(탭이 입력칸으로).
- 마지막 탭 뒤 ＋(새 세션 · 에이전트가 둘이면 고르기).
- 오른쪽 끝 단추 하나: 가려진 탭이 있으면 «＋N ▾»(가려진 것 가운데 가장 급한 상태 점 하나), 없고 자동화 세션이 있으면 «자동화 N ▾», 둘 다 없으면 단추가 없다. 누르면 목록(`Float`): 가려진 세션 줄 → 구분선 → «자동화 N»(접힘 · 기억은 지금 값 그대로).
- 폭 재기: 보이지 않는 측정 줄에 모든 탭을 그려 폭을 읽고(`ResizeObserver` — 채팅 칸 폭 · 세션 목록 · 이름이 바뀔 때) `fitTabs` 로 가른다.
- 세션이 하나도 없으면 줄에 «＋ 세션 시작» 하나.
- 키보드: 탭은 `button`. ⌘N · ⌘⇧B 등 기존 단축키는 그대로.

**폰**: 줄을 세우지 않는다. 머리줄 단추가 세션 이름과 상태 점을 보이고, 누르면 바닥 시트(줄 44px · 새 세션 · 자동화 접힘). 줄의 ✕ · 이름 고치기는 줄 끝 단추로(올리기가 없다).

### 묶음 2 — 오른쪽 패널

- 개요 칸(`Overview`): 호스트가 한 번 계산해 준다 — 새 길 `GET /bots/:id/overview` → `{ goal?: string; goalAt?: number; mine: { asks: number; proposed: number; due?: string }; recent: { rel: string; at: number }[]; hasState: boolean }`. 첫 줄은 `state.md` 의 «현재 목표» 줄 그대로(모델을 부르지 않는다). `state.md` 가 없으면 «state.md 가 없어요 — 봇에게 정리를 시키기». 계산은 `src/core/overview.ts`(순수 · 유닛) + 호스트 길.
- 고정 높이(`secH` · 끌어서 조절)를 없애고, 할 일 칸은 내용만큼(최대 패널 높이의 45%) · 잘리면 «＋N 더»(누르면 그 칸이 펼쳐진다). 파일 칸이 남는 높이를 쓴다.
- 도구 막대: 루틴 N · 명령·스킬 · ⋯(모두 읽음 · 색 · 빼기 · 은퇴). 지금의 «명령·스킬» 절 · «루틴» 절 · 발의 «이 봇» 줄이 여기로 간다(누르면 지금 내용이 `Float` 로).
- 폰 «폴더» 탭: 개요 · 파일 · 도구 막대.
- 오케스트레이터 패널(«이 볼트에서»)은 같은 틀, 개요 자리는 비운다(미정).

### 묶음 3 — 왼쪽 목록 A안

- 위에서부터: 찾기 · 폴더 선택 → «내 답을 기다림» 띠(있을 때만 · 최대 세 줄 · 넘으면 «외 N — 상황판에서») → 봇 목록 → 상황판 한 줄 → 숫자 줄(세션 · 알림 · 할 일 · 루틴 문제 · 설정).
- 숫자는 모두 «내가 볼 것»: 세션 = 안 읽은 수 · 알림 = 안 읽은 수 · 할 일 = 열린 수 · 루틴 = 문제 수. 0 이면 이름만.
- 정렬(마감일 · 사용자 · 상태)은 봇 목록 머리의 단추 하나로 접는다.
- 스모크 `CX-1`~`CX-5` 가운데 레일을 재는 검사를 함께 고친다.

## 새 화면 검사 `test/session-strip.mjs`

1. 데스크톱: 세션 셋이면 탭 셋과 ＋ 가 한 줄(높이 34 이하)에 서고 넘침 단추가 없다.
2. 세션 아홉(임시 볼트에 만들어 넣는다)이면 줄 높이가 그대로이고 `.smore` 에 «＋N» · 가로 넘침 없음 · 지금 보는 세션 탭이 보인다.
3. 가려진 세션을 목록에서 고르면 그 세션으로 가고 그 탭이 줄에 보인다.
4. 채팅 칸을 330 으로 줄여도(문서 칸 열기) 줄이 한 줄이고 지금 보는 탭이 보인다.
5. 탭 두 번 누르기 → 이름 고치기 → ⏎ 저장(호스트 값 확인). 탭 ✕ → 되돌리기 토스트.
6. 자동화 세션은 탭이 아니고 목록의 «자동화» 아래에만 있다.
7. 뒤에서 도는 일: 진행 줄 단추 → 팝오버(오른쪽 패널에 «뒤에서 도는 일» 칸이 없다).
8. 폰(390): 머리줄에 세션 이름 · 누르면 시트(줄 44px 이상) · 시트에서 고르면 바뀜 · «할 일» 탭에 세션 줄이 없다.

## 위험

- 스모크 60여 곳이 패널의 세션 줄을 잰다. 선택자만 바꾸면 되는 것과 흐름이 달라지는 것(자동화 펼치기)을 갈라 옮긴다.
- 탭 폭 재기는 글꼴이 늦게 뜨면 틀린다 — `document.fonts.ready` 뒤 한 번 더 잰다.
- 측정 줄이 가로 넘침을 만들면 폭 검사(`fit.mjs`)가 빨강 — 측정 줄은 `position:absolute; visibility:hidden; width:0; overflow:hidden` 안에 둔다.
- 폰 머리줄이 두 줄이 되면 높이가 달라진다 — 머리줄 높이는 그대로 두고 글자 크기로 맞춘다(`docs/LAYOUT.md` 불변식).
