## S1. 첫 실행 — 미니에 깔고 10분 안에 폰에서 첫 지시

**상황.** 새 Mac mini. Dropbox 에 PARA 볼트가 이미 있다. Claude Code 는 로그인돼 있다.

**흐름.**
1. Mac mini 에서 호스트 앱을 연다. 루트 폴더로 `…/PARA` 를 고른다.
2. **폴더 규칙 프리셋**을 고른다: PARA(기본) · Johnny.Decimal · 내 방식대로. PARA 를 고르면 루트 `CLAUDE.md` 에 `## 폴더 규칙` 절이 설치된다(이미 있으면 절만 덧붙임).
3. 규칙으로 스캔 → 후보 12개. 오케스트레이터가 첫 인사: *"최근 활발한 폴더 3개(제품_Rondo · 재무_CFO · 강의_FoundersAI-2기)에서 시작할까요?"* → [시작].
4. 연결: Tailscale 이 켜져 있으면 주소와 QR 을 보여 준다. 폰에서 열면 페어링 코드 6자리.
5. 폰 목록에 봇 3개 + 오케스트레이터. 제품_Rondo 를 열어 첫 지시를 보낸다.

**화면.** S1a 프리셋 선택 · S1b 오케스트레이터 첫 인사(3개 제안) · S1c 폰에서 열기(주소·QR·코드) · S1d 폰 첫 목록.
**성공 기준.** 설치 시작부터 폰에서 첫 응답까지 10분. 만든 것은 없다(폴더도 봇도 설정도).
**실패 모드.** Tailscale 미설치 → 안내만 하고 대신 깔지 않는다. 루트에 `CLAUDE.md` 가 있으면 덮지 않고 절만 붙인다.

## S2. 폴더에서 시작 — 고르거나, 만들어서

**상황.** 새 자문 건(하이드미플리즈)이 생겼다. 폴더가 아직 없다.

**흐름.**
1. 왼쪽 맨 위 `＋ 폴더 선택 · 에이전트 시작`.
2. 피커: *"에이전트와 함께 일할 폴더를 선택하세요"*. `2. Projects` 첫 줄 **새 폴더 만들기** → 이름 `하이드미플리즈-자문` 입력 → 규칙의 naming 으로 `2026-09_하이드미플리즈-자문` 미리보기.
3. [이 폴더에서 시작] → 폴더 생성 + 하네스 스캐폴드(CLAUDE.md·readme.md·todo.md·`.claude/`) → 봇이 목록에 나타난다(색 자동).
4. 봇 첫 화면: 시스템 줄 *"폴더를 만들고 하네스를 깔았어요. readme.md 에 이 일이 무엇인지 적어 두면 제가 기억합니다."* → 첫 지시.
5. 대안 경로: 오케스트레이터에게 *"하이드미플리즈 폴더에서 시작해"* → 없으면 만들지 물어봄 → 승인.

**화면.** S2a 피커(기존) · S2b 새 폴더 이름 입력 + naming 미리보기 · S2c 새 봇 첫 대화.
**성공 기준.** 이름 한 번 치는 것 외에 설정이 없다. 하네스 없는 기존 폴더를 골라도 같은 스캐폴드.

## S3. 이동 중 승인·지시 — 폰이 잠겨 있어도

**상황.** 제품_Rondo 봇에게 QA 를 돌리라고 시켜 두고 지하철을 탔다.

**흐름.**
1. 봇이 `npm run qa` 를 실행하려다 멈춘다 → 상태 **확인해 주세요** → 폰에 푸시: *"제품_Rondo · 확인해 주세요 · Bash: npm run qa"*.
2. 푸시를 누르면 그 대화로 바로 간다. 승인 카드 [허용] [항상 허용] [거부].
3. [허용] → 봇이 계속. 도구 줄이 흐른다. 끝나면 **끝났어요** + 푸시 *"QA 통과 · 3건 수정"*.
4. 한 줄 지시: *"통과했으면 커밋하고 PRD 변경 이력에 한 줄 적어"* → 같은 세션이 이어서 한다.
5. 폰을 끄고 30분 뒤 켜도 같은 대화·같은 세션. 저장된 메시지가 먼저 보이고 연결되면 갱신.

**화면.** S3a 폰 알림 배너 · S3b 승인 카드(기존 Phone) · S3c 끝났어요 + 후속 지시.
**성공 기준.** 잠긴 폰에서 두 번 탭으로 승인. 세션이 폰 상태와 무관하게 산다.

## S4. 파일 확인·편집 — IDE 를 열지 않고

**상황.** 봇이 PRD 를 고쳤다고 한다. 어디를 고쳤는지 보고 한 문장만 손보고 싶다.

**흐름.**
1. 봇 메시지 아래 칩 `📄 docs/PRD.md` 를 누른다 → 오른쪽에서 시트가 슬라이드. 대화는 뒤에 그대로.
2. 시트 상단: 파일명 탭 · 동기화 점(초록=Dropbox 반영됨) · [편집] · 새 창으로 · 닫기.
3. [편집] → 그 자리에서 문장을 고친다 → 저장(바이트 보존). 동기화 점이 회색(확인 중) → 초록.
4. [이 파일로 말하기] → 컴포저에 칩이 들어간다 → *"§4.2 를 세 줄로 줄여"*.
5. 폰에서는 같은 시트가 전체 높이로 뜬다. 편집은 todo 체크·짧은 노트까지.

**화면.** S4a 시트(기존 FileSheet) · S4b 편집 모드 + 동기화 점 전이.
**성공 기준.** 대화를 떠나지 않는다. 저장 후 원본 바이트가 같다(변경한 줄 제외).

## S5. Inbox 정리 — 던지면 규칙대로

**상황.** Finder 에서 받은 폴더 `유메타랩_자문자료` 와 PDF 3개를 `1. Inbox` 에 넣어 뒀다.

**흐름.**
1. 호스트가 Inbox 변화를 감지 → 오케스트레이터가 규칙(§3.5)을 읽고 제안 카드를 보낸다:
   - `유메타랩_자문자료` → `3. Area/사업_자문-유메타랩/자료/` 로 이동 (기존 Area 와 이름 유사도 근거)
   - PDF 3개 → 같은 폴더 `자료/` 로
   - 하네스: 있음(건드리지 않음)
2. [승인] → 이동(되돌리기 스냅샷) → *"정리했어요. 사업_자문-유메타랩 봇을 시작할까요?"* → [시작].
3. 매일 07:00 루틴이 남은 Inbox 를 다시 제안한다(S6).
4. 규칙이 마음에 안 들면: *"자문 자료는 Resources 로 보내"* → 오케스트레이터가 규칙 절을 고치자고 제안 → 승인.

**화면.** S5a 제안 카드 · S5b 승인 후 — 봇 시작 제안 + 목록에 새 봇.
**성공 기준.** 사람이 옮기는 폴더 0개. 잘못 옮긴 건 [되돌리기] 한 번.

## S6. 루틴 — 사람이 없을 때

**상황.** 제품_Rondo 폴더 `.bot.yml` 에 루틴 둘: 매일 07:00 todo 리마인드 · 일요일 20:00 주간 회고.

**흐름.**
1. 07:00 호스트 스케줄러가 봇 안에 세션을 하나 띄워 프롬프트를 보낸다(읽기 전용 정책).
2. 결과가 대화에 **루틴 카드**로 남는다: 미완료 4건 체크리스트 + "오늘 하나만 고르면?" 제안. 폰 푸시 한 줄.
3. 카드에서 바로 체크 → `todo.md` 가 고쳐진다(호스트가 대신 씀).
4. 루틴 편집: 오른쪽 패널 `루틴 2` → 시트에서 cron·프롬프트·승인 정책 수정 → `.bot.yml` 저장.
5. 오케스트레이터 루틴(일요일): 각 봇 진행 요약 + 아카이브 후보 제안(S9).

**화면.** S6a 루틴 카드(체크리스트) · S6b 루틴 편집 시트.
**성공 기준.** 루틴은 파일이다(`.bot.yml`). 사람이 없을 때 파일을 쓰지 않는다(제안만).

## S7. 관제 — 지금 뭐 돌고 있어?

**상황.** 봇 5개가 활성. 회의 전 3분.

**흐름.**
1. 오케스트레이터에게 *"지금 뭐 돌고 있어?"* → 표 한 장: 봇 · 상태 · 세션 · 마지막 산출물 · 기다리는 것. 확인 대기가 있으면 맨 위 + 바로 가기.
2. *"이 초안(칩)을 재무 봇은 숫자 검토, 강의 봇은 사례 보강으로 나눠서 시켜"* → 오케스트레이터가 두 봇에 세션을 하나씩 만든다(`bot_send`) → 위임 카드 2장(각 봇으로 점프).
3. 둘 다 끝나면 오케스트레이터가 취합 메시지 + 파일 칩.
4. 동시 세션 상한(봇당 4·호스트 12)에 걸리면 *"강의 봇은 이미 4개가 돌고 있어요. 하나 끝나면 이어서 할까요?"*.

**화면.** S7a 상태 표 메시지 · S7b 위임 카드 2장 + 취합.
**성공 기준.** 봇 목록을 안 훑어도 3분 안에 상황 파악. 위임은 한 문장.

## S8. 끊김·복구 — 미니가 조용히 죽지 않는다

**상황.** Claude CLI 가 갱신되며 미니의 키체인 접근이 어긋났다. 봇들이 새 세션을 못 띄운다.

**흐름.**
1. 호스트 인증 워치독이 30분 주기 판정에서 **"이 문맥에선 못 읽음"** 을 잡는다(로그아웃과 구별).
2. 폰 푸시: *"Mac mini 에서 Claude 로그인이 필요해요. Jump Desktop → 터미널 → /login"*. 앱 상단에 앰버 배너 + 런북 링크.
3. Dave 가 Jump Desktop 으로 들어가 `/login`. 호스트가 다음 판정에서 복귀 → 배너 사라짐 → 밀려 있던 지시가 이어진다.
4. 네트워크 끊김은 다르게 보인다: 클라이언트가 *"저장된 메시지 표시 중 · 연결되면 갱신"* 을 띄우고 재연결.

**화면.** S8a 폰 푸시 + 앰버 배너 · S8b 데스크톱 배너(저장된 메시지 표시 중 / 인증 필요).
**성공 기준.** 조용한 실패 0. 두 종류의 끊김(인증·네트워크)이 다른 문장으로 보인다.

## S9. 정지·은퇴 — 끝난 일은 Archive 로

**상황.** 강의 2기가 끝났다.

**흐름.**
1. 봇 헤더 `⋯` → 정지(휴면, 기록 유지) / **Archive 로 이동(은퇴)**.
2. 은퇴 확인: *"`2. Projects/2026-09_강의-FoundersAI-OS-2기` 를 `5. Archive/` 로 옮깁니다. 세션 기록과 루틴은 보관되고 봇은 목록에서 사라집니다."* → [옮기고 은퇴].
3. 오케스트레이터 주간 회고가 먼저 제안할 수도 있다: *"2주간 활동 없는 프로젝트 2개 — 아카이브할까요?"*.
4. 되돌리기: Archive 에서 다시 `2. Projects` 로 옮기면 후보로 돌아온다.

**화면.** S9a 헤더 메뉴 + 은퇴 확인.
**성공 기준.** 폴더 이동 = 봇 수명주기. 별도 "봇 삭제" 개념이 없다.

## S10. 할 일 — todo.md 하나, 쓰임은 둘

**상황.** 제품_Rondo 봇이 QA 를 돌리고 커밋했다. 변경 이력 한 줄은 못 적었고, Dave 는 Tailscale 을 아직 폰에 안 깔았다.

**흐름.**
1. 봇이 대화에서 *"변경 이력 줄은 할 일에 남겨 뒀어요 — 다음 세션에서 제가 할게요"* + 카드(봇 표식). 같은 메시지에서 *"Dave 가 할 것: Tailscale 폰 설치"* 를 상기시킨다.
2. Dave: *"알파 동결 문서 쓰는 것도 내 할 일로 넣어 줘 — 설명은 「PRD v1.0 뒤에」"* → 봇이 `- [ ] 알파 동결 문서 쓰기: PRD v1.0 뒤에.` 를 추가.
3. 오른쪽 패널 상단 "할 일 · 미완료 4" 에 바로 보인다. 클릭 → 시트: 전체 목록, 상단 입력줄(`제목: 설명`), 봇 표식, 완료 절.
4. 시트에서 항목을 골라 **봇에게 맡기기** → 제목·설명이 그대로 지시가 된다.
5. 다음 세션 시작 시 봇은 자기가 남긴 항목을 먼저 처리하고 체크한다. 아침 루틴(S6)이 미완료를 리마인드한다.

**화면.** S10a todo 시트 · S10b 봇이 할 일을 남기고, 사용자가 추가하는 대화.
**성공 기준.** 문법은 한 줄 = 제목: 설명 뿐. 누가 적었는지 보인다. Obsidian 에서 열어도 그냥 체크리스트다.

## S11. 목록 정리 · 알림 — 봇이 12개일 때

**상황.** 활성 봇 12개. 회의 중이라 앱을 열 수 없는데 재무 봇이 외부 발송 승인을 기다린다.

**흐름.**
1. 메뉴바의 폴더봇 아이콘이 **입을 벌리고 배지 2** 를 단다(두 번 콩콩). 클릭 → 팝오버: "둘이 당신 차례를 기다려요" + 확인 대기 카드 2장 → [보내기] 를 팝오버에서 누른다. 앱은 열지 않았다.
2. 동시에 맥 알림 센터 배너에도 같은 카드가 [허용][열기][거부] 로 떴다. 한쪽에서 처리하자 다른 쪽과 폰 푸시가 사라진다.
3. 저녁에 앱을 열고 왼쪽 목록이 길어 **정렬 메뉴**를 연다: 확인 대기 먼저 → 최근 활동, PARA 범주 접기, 촘촘. 폭을 드래그해 넓힌다. 메뉴 하단 "활성 12 / 상한 8 — 휴면 3개를 은퇴시키면 가벼워져요".
4. 왼쪽 하단 종 → 앱 안 알림 센터에서 오늘 이벤트를 훑고 읽음 처리. 알림 설정에서 강의 봇의 폰 푸시를 끄고 조용한 시간을 확인한다.

**화면.** S11a 왼쪽 목록 3상태 + 정렬 메뉴 · S11b 맥 배너 · 메뉴바 · S11c 알림 센터 · 설정 · S11d 메뉴바 아이콘 표정 6종 + 팝오버.
**성공 기준.** 앱을 안 열고 승인이 끝난다. 봇 12개여도 확인 대기가 항상 맨 위에 있다.
